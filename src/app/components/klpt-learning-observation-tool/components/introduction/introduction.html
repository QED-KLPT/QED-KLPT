The Learning observation tool within the KLPT generates meaningful data and helps to inform ‘where to next’ in the progression of learning for individual children. It does this by helping teachers and educators identify observable behaviours linked to each learning domain. The tool generates a learning statement, with the option to add context, reflections, and strategies to support each child's ongoing progress. The learning observation tool is a point in time assessment for children’s learning. It is not for summative assessment or ranking children and should not involve testing or removing children from their everyday play and learning.

The following fact sheet provides an overview of the Learning Observation Tool and how it supports formative assessment in kindergarten contexts. It explains the learning progressions, observable behaviours and learning statements, and highlights how the tool can be used to recognise children’s strengths, inform planning and support ongoing learning and positive transitions.
